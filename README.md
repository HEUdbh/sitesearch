# SiteSearch 项目

一个集成 OneForAll 域名收集工具的综合站点搜索与分析平台。

## 项目简介

SiteSearch 是一个专为安全研究人员、渗透测试人员和网络管理员设计的综合工具平台，主要功能包括：

- 基于 OneForAll 的高效子域名收集
- 站点信息在线展示与管理
- RESTful API 接口支持
- 任务管理与执行结果持久化存储
- 现代化的前端界面

## 项目结构

```
sitesearch/
├── OneForAll/      # OneForAll 子域名收集工具
├── siteback/       # 后端服务
│   ├── api/        # API 路由定义
│   ├── app/        # 应用主程序
│   └── code/       # 核心代码模块
└── sitevue/        # 前端 Vue 项目
```

### OneForAll

强大的子域名收集工具，提供多种子域名收集方式，包括但不限于：
- 证书透明度日志
- 搜索引擎
- DNS 记录
- 域名爆破
- 爬取

### siteback

后端服务，基于 Python 开发，主要功能：
- 提供 RESTful API 接口
- 管理 OneForAll 任务的执行
- 数据库存储与查询
- 任务状态监控

### sitevue

基于 Vue.js 的现代化前端界面，提供：
- 用户友好的交互界面
- 任务创建与管理
- 结果可视化展示
- 实时状态更新

## 安装部署

### 环境要求

- Python 3.7+
- Node.js 14+
- MySQL 5.7+

### 安装步骤

#### 1. 克隆项目

```bash
git clone [仓库地址]
cd sitesearch
```

#### 2. 后端安装

```bash
cd siteback
# 安装依赖
pip install -r requirements.txt
# 配置数据库连接
# 启动服务
python -m app.main
```

#### 3. 前端安装

```bash
cd ../sitevue
# 安装依赖
npm install
# 开发模式运行
npm run dev
# 或构建生产版本
npm run build
```

## 使用说明

### API 接口

#### 运行子域名收集任务
- **接口**: `/api/run`
- **方法**: `POST`
- **参数**:
  - `target`: 目标域名
  - `module`: 执行模块
  - `targets`: 多个目标（可选）
- **返回**: 任务 ID 和状态

#### 获取任务状态
- **接口**: `/api/status/<task_id>`
- **方法**: `GET`
- **返回**: 任务状态信息

#### 获取任务列表
- **接口**: `/api/tasks`
- **方法**: `GET`
- **返回**: 所有任务列表

#### 获取任务结果
- **接口**: `/api/results/<task_id>`
- **方法**: `GET`
- **参数**:
  - `page`: 页码
  - `limit`: 每页数量
- **返回**: 分页的任务结果

#### 停止任务
- **接口**: `/api/stop/<task_id>`
- **方法**: `GET`
- **返回**: 停止结果

#### 清理任务
- **接口**: `/api/cleanup`
- **方法**: `GET`
- **返回**: 清理结果

### 数据库设计

系统使用 MySQL 数据库，主要表结构：

#### tasks 表
- 存储任务基本信息
- 包含任务 ID、目标、模块、状态、开始时间、结束时间等

#### results 表
- 存储任务执行结果
- 包含子域名、IP、端口、服务等详细信息
